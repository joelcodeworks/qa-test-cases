### ID: TC-FILTER-001

## Objective:
Verify that applying a filter displays only the information corresponding to the selected criteria.

## Preconditions:
- The application is accessible.
- The user is on the main page.
- The filter controls are available.
- No authenticated account is required for this test.

## Steps:
1. Open the application.
2. Navigate to the section containing the available filters.
3. Select one of the available filters.
4. Apply the selected filter.
5. Observe the displayed information.

## Expected Result:
Only the information corresponding to the selected filter is displayed.

## Actual Result:
The selected filter was applied correctly and the displayed information matched the selected criteria.

## Status:
Pass

## Priority
Medium

## Environment:
macOS

## Browser:
Firefox / Safari

## Notes:
The filter was tested successfully in both Firefox and Safari. No unexpected behavior was observed.
